# Roki po Polsku | Polish Year Listening & Grammar Cases Practice

A modern, interactive web application to help Polish language learners practice listening to and writing Polish years across various prepositions and grammatical cases (Locative, Genitive, Accusative, Instrumental).

## Features
- **Comprehensive Case & Preposition Practice**:
  - `w ... roku` (*in ...* - Locative)
  - `od ... roku` (*since ...* - Genitive)
  - `do ... roku` (*until ...* - Genitive)
  - `z ... roku` (*from / of ...* - Genitive)
  - `na rok ...` (*for the year ...* - Accusative)
  - `przed ... rokiem` (*before ...* - Instrumental)
  - `po ... roku` (*after ...* - Locative)
- **Web Speech API Audio Player**: Normal (1.0x) and slow (0.55x) playback speeds using native browser Text-to-Speech voices.
- **Flexible Answer Validation**: Accepts full year phrases (e.g. `w 1916 roku`), preposition + year (`w 1916`), just digits (`1916`), or written Polish words.
- **Glassmorphic UI**: Built with dark mode glassmorphism aesthetics, responsive layouts, session statistics, and session history tracking.

## Technology Stack
- **HTML5 & CSS3** (Vanilla Glassmorphism Design System)
- **JavaScript (ES6+)** with Web Speech API
- **GoatCounter Analytics**
